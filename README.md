Nombre del proyecto: Comedor Caritas Felices

 Descripción: Sitio web para el Comedor y Merendero Caritas Felices, una organización comunitaria de La Plata. El comedor brinda merienda y cena a más de 400 personas todos los días, ofrece apoyo escolar a niños y niñas y organiza colectas solidarias. El sitio presenta su historia, sus actividades y las distintas formas de colaborar.
